Guía de Administración de Sistemas

Bienvenidos a esta guía basica sobre administración de sistemas en red

1. Intalación del sistema operativo

Primero, se debe elegir el sistema operativo adecuado según las necesidades del entorno

1.1 Requisitos previos

Verifica el hardware, la compatibilidad y realiza una copia de seguridad.

1.2 Proceso de intalación

Utiliza un medio de instalación de sistema, se debe configurar la red para permitir la conectividad.

2. Configuración de Red

una ves instalado el sistema (USB,DVD) y sigue los pasos de asistente.

2.1 Dirección IP y DNS

Configura una IP estática o dincamica y define los servicios DNS.

2.2 Pruebas de conectividad

Usa comandos como ping o traceroute para verificar la conexión.
